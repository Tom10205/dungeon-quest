Dungeon Quest — проект для сборки APK

Как собрать APK через GitHub без Android Studio:

1. Войди на github.com и создай новый публичный репозиторий с именем dungeon-quest.
2. Распакуй этот ZIP.
3. Загрузи ВСЕ файлы и папки из архива в корень репозитория. Не забудь папку .github/workflows и папку www.
4. Открой вкладку Actions.
5. Если GitHub предложит включить Actions — включи.
6. Выбери Build Dungeon Quest APK и нажми Run workflow. Также сборка запускается после загрузки файлов в ветку main.
7. Дождись зелёной отметки успешной сборки.
8. Открой завершённый запуск и скачай артефакт Dungeon-Quest-debug-APK.
9. Распакуй скачанный ZIP. Внутри будет app-debug.apk. Открой его на Android и разреши установку из этого источника, если система спросит.

Примечание: это тестовый debug APK, не релиз для Google Play. Для публикации понадобится отдельная подписанная release-сборка.
